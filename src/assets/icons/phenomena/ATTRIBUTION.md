- spiral-arrow — by [Lorc](http://lorcblog.blogspot.com)

Used as approximate visual stand-ins for GEOBIO's phenomenon kinds (no exact
matches exist for esoteric/geobiology-specific concepts in a generic icon
set): chimney → cheminée-1/2/3/4 (with a small branch-count badge),
spiral-arrow → spire de vortex, star-formation → point cosmique,
tic-tac-toe → carré magique, obelisk → tube magique.

Icons were stripped of their default black background square and switched
from a fixed white fill to `currentColor` so they can be recolored via CSS —
the artwork itself is unmodified.
